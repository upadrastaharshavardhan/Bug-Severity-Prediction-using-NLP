Experimental Results

Strong classification performance.

The research package reports high overall accuracy together with strong macro-averaged and critical-class F1 performance.

Model Performance

Accuracy 95.60%
Macro F1 0.955
Critical F1 0.968

Why These Metrics Matter

Accuracy measures overall correctness, while Macro F1 gives equal importance to the individual classes. Critical-class F1 provides a focused view of how effectively the system identifies the most important bug category.

In production, these metrics should be monitored continuously against project-specific data and severity distributions.

Reproducibility

Reproduce the experiment.

The repository provides a deterministic workflow for generating the experimental dataset and training the model. 

# Clone repository
git clone https://github.com/upadrastaharshavardhan/Bug-Severity-Prediction-using-NLP.git

# Enter project
cd Bug-Severity-Prediction-using-NLP/codebase

# Install dependencies
pip install -r requirements.txt

# Generate reproducible dataset
python scripts/generate_data.py --n-samples 4000 --seed 42

# Train model
python scripts/train.py
